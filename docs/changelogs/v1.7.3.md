# Cozystack v1.7.3

Cozystack v1.7.3 is a security patch release on the v1.7 line.

## Security

* **Security fix in the monitoring package**: fixes a critical security issue in the monitoring package. Details will be in a GitHub security advisory, please upgrade as soon as possible ([**@kvaps**](https://github.com/kvaps) in cozystack/cozystack@9189218).

## Migration and Upgrades

The release adds no platform migration: `migrations.targetVersion` is 61 at both v1.7.2 and v1.7.3.

* **Monitoring web UI login**: a monitoring web UI gets login credentials of its own after the upgrade, shown to tenants as a separate Secret.
* **Sign in again**: the upgrade resets sessions of that monitoring web UI, so its users have to sign in again.
* **Rotate credentials**: rotate the Grafana admin password and the API keys of that web UI issued before the upgrade, and revoke the old keys in that web UI, the upgrade does not change or revoke them.

**Full Changelog**: https://github.com/cozystack/cozystack/compare/v1.7.2...v1.7.3
