# S3 bucket

## Parameters

### Parameters

| Name                      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Type                | Value   |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ------- |
| `locking`                 | Provisions bucket from the `-lock` BucketClass (with object lock enabled).                                                                                                                                                                                                                                                                                                                                                                                                                          | `bool`              | `false` |
| `lockingDefaultRetention` | With `locking`, keeps the default retention of the `-lock` BucketClass (COMPLIANCE, 365 days). Set to `false` to provision from the `-lock-noretention` BucketClass instead: Object Lock is enabled with no default retention, and retention is then set on the bucket or per object through the S3 API. Read at creation only.                                                                                                                                                                     | `bool`              | `true`  |
| `storagePool`             | Selects a specific BucketClass by storage pool name.                                                                                                                                                                                                                                                                                                                                                                                                                                                | `string`            | `""`    |
| `ui`                      | Deploys the web UI (s3manager) with its Service and its Ingress or HTTPRoute at `<bucket>.<tenant host>`. Set to `false` to run the bucket without them.                                                                                                                                                                                                                                                                                                                                            | `bool`              | `true`  |
| `publicRead`              | Serves the bucket's objects to anyone without credentials at `<endpoint>/<bucket>/<key>`. Anonymous callers can read objects but cannot list the bucket or write to it.                                                                                                                                                                                                                                                                                                                             | `bool`              | `false` |
| `users`                   | Users configuration map.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `map[string]object` | `{}`    |
| `users[name].readonly`    | Whether the user has read-only access.                                                                                                                                                                                                                                                                                                                                                                                                                                                              | `bool`              | `false` |
| `users[name].platform`    | Marks a platform account, such as the `system` user of the backup bucket, which backupstrategy-controller sets. Its keys stay in the `<bucket>-<user>-credentials` Secret, which no tenant can read, and are never minted. Clearing it drops the chart-rendered BucketAccess, which revokes those keys, and the user becomes a normal account whose keys are minted through its Credential. Leave it unset for your own users.                                                                      | `bool`              | `false` |
| `schedulingClass`         | Name of a SchedulingClass CR (cluster-scoped, group cozystack.io) used in place of the tenant's for this application's pods. A pod gets its class when it is created, so running pods keep theirs until they are recreated. Must be the tenant's own class or one listed in the tenant's `allowedSchedulingClasses`. Setting any other value is refused, and the pods of an application whose class is not, or no longer, in that list get the tenant's class. Empty means inherit from the tenant. | `string`            | `""`    |
